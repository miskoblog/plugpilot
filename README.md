# PlugPilot

A free bonus toolkit for the SuperPlug AI launch: **Plan. Brief. Price.**

- **CreditWise** — Credit Budget Planner, Spending Guardrail Calculator, Credit Ledger & Burn-Down
- **Briefed** — One-Sentence Brief Builder, Brand Kit Prep Sheet, Revision Request Sharpener
- **Priced** — Deliverable Rate Calculator, Monthly Retainer Package Builder, One-Page Price Sheet

Fully static: plain HTML/CSS/JS, no build step, no API calls, no backend. Everything a user enters or saves
stays in their own browser (`localStorage`). The password gate is a client-side deterrent, not real security.

Live at https://plugpilot.misanmorrison.com/
